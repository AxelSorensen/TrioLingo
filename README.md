# 🈁 TrioLingo

A placeholder for a planned translation app — currently just the unmodified Vite + React starter.

## Features

- ⚡ **Vite + React scaffold** — fast HMR dev setup, ready for a real app to be built on top

## Installation

```bash
git clone <this repo>
cd TrioLingo
npm install
```

## Usage

```bash
npm run dev
```

Opens the default Vite dev server (see terminal output for the URL, typically [http://localhost:5173](http://localhost:5173)).

## Built with

- [React](https://reactjs.org/) 18
- [Vite](https://vitejs.dev/)

## Status

📦 Unstarted — the `App.jsx`, styles, and README are still the default `create-vite` template (package name is `translate`); no translation/language features have been built yet.
